How to use in nRF Connect
1
Tap Regenerate immediately before writing to get the freshest timestamp, then tap Copy.
2
Open nRF Connect → Scanner → connect to your sensor node.
3
Go to Client tab → expand service f0debc9a.
4
Find characteristic aabbccdd-eeff-0011 → tap the ↑ write arrow.
5
Set type to Write Request, format to HEX, paste the copied value and tap Write.
6
Sensor node log should show time_sync: synced UTC=... confirming success.
